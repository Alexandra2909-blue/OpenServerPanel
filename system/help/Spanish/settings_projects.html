Configuración Global de Proyectos

Los parámetros establecidos en esta sección se utilizan cuando no se especifican otros valores en la configuración del proyecto.

HTTP
Define el tipo de servidor web utilizado para los proyectos.
NODE
Especifica el motor Node.js para ejecutar aplicaciones Node.js.

Instalación de Node.js: Primero instale la versión requerida de Node.js usando el complemento NVM.
PHP
Define el motor PHP utilizado para procesar archivos PHP.
Habilitar
Define el estado predeterminado del proyecto (habilitado o deshabilitado).
Codificación del Terminal
Codificación del terminal al trabajar con el entorno del proyecto.

Valores especiales:
- system: Utiliza la codificación del sistema.

Importante: Si el valor no está establecido, al formar el entorno final del proyecto, la codificación del terminal será establecida por el último entorno conectado donde esté definida, por ejemplo, el entorno del módulo PHP.
IP
Establece la(s) dirección(es) IP utilizada(s) por todos los proyectos sin configuraciones individuales.

Limitación: Los proyectos que usan la misma dirección IP deben ejecutarse en la misma versión de PHP.

Soporte de múltiples IP: Puede especificar múltiples direcciones IP separadas por espacios, incluyendo IPv6. En el archivo HOSTS, a los dominios se les asignará la primera IP especificada.

Asignación automática: Si deja el campo vacío, la dirección IP se asignará automáticamente.

Recomendaciones:
  • La gestión automática de direcciones IP se recomienda para la mayoría de usuarios.
  • La configuración manual de dirección IP solo debe utilizarse para requisitos específicos de configuración de red.
HTTP
Define el puerto para conexiones HTTP.
HTTPS
Define el puerto para conexiones HTTPS.
SSL
Habilita o deshabilita el soporte SSL para proyectos sin configuraciones individuales.
H2
Habilita o deshabilita el soporte HTTP/2 para proyectos sin configuraciones individuales.
Archivo de Certificado
Especifica la ruta al archivo de certificado SSL. Se pueden usar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:

Recomendación: Deje el campo vacío para la generación automática de certificados.
Archivo de Clave
Especifica la ruta al archivo de clave SSL. Se pueden usar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:

Recomendación: Deje el campo vacío para la generación automática de claves.
Dirección IP (backend)
Especifica la dirección IP para conectarse al backend.
Puerto (backend)
Define el número de puerto para conectarse al backend.
Habilitar (backend)
Permite la redirección automática de todo el tráfico entrante del proyecto (HTTP y HTTPS) al backend. Útil para pruebas o desarrollo cuando el frontend y backend están separados.
Directorio del Proyecto
Especifica el directorio raíz del proyecto. La navegación a este directorio se realiza con el comando osp project <DOMAIN> junto con la activación del entorno del proyecto. Se pueden usar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:
Directorio Público
Define el directorio público del proyecto. Se pueden usar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:
Alias
Especifica nombres de dominio adicionales (alias) para el proyecto (separados por espacios). Se pueden usar variables de plantilla.

Subdominios: Si un alias no contiene un punto, se trata como un subdominio (ej. "www" -> "www.test.local").

Limitación: El símbolo "*" no es compatible con el archivo HOSTS de Windows y requiere configuración DNS.
Entorno del Proyecto
Lista de complementos y módulos (separados por espacios) que forman el entorno del proyecto.

Módulos PHP/Nginx/Node.js: Los entornos de estos módulos siempre se conectan (si se especifican para el dominio) y no requieren especificación en este parámetro.
Comando de Inicio del Proyecto
Define el comando para iniciar el proyecto (ej. nodemon app.js). Se pueden usar variables de plantilla.
URL del Proyecto
URL que se abre al seleccionar Abrir proyecto en navegador en Open Server Panel. Se pueden usar variables de plantilla.

Aplicación: Puede establecer la URL del panel de administración del CMS.

Variables de Plantilla

Variable Descripción
{backend_ip} Dirección IP de conexión al backend
{backend_port} Puerto de conexión al backend
{base_dir} Directorio raíz del proyecto (donde se encuentra el directorio .osp)
{host} Nombre del dominio (se usa Punycode para dominios internacionalizados)
{host_decoded} Nombre de dominio visible (sin Punycode)
{host_scheme} Esquema de solicitud del proyecto ("http" o "https", depende del parámetro SSL en la configuración del proyecto)
{http_port} Puerto de solicitud del proyecto vía protocolo HTTP
{https_port} Puerto de solicitud del proyecto vía protocolo HTTPS
{web_engine} Motor HTTP
{node_engine} Motor NODE
{php_engine} Motor PHP
{project_dir} Directorio raíz del proyecto
{public_dir} Directorio público del proyecto
{scheme_port} Puerto de solicitud del proyecto (":{http_port}" o ":{https_port}", depende del parámetro SSL en la configuración del proyecto).

Si {http_port} o {https_port} tiene valor estándar 80 o 443, entonces {scheme_port} estará vacío.
{root_dir} Directorio raíz de Open Server Panel (ruta completa)
{root_drive} Unidad del directorio raíz
{root_path} Ruta al directorio raíz de Open Server Panel
{terminal_codepage} Codificación de la consola
