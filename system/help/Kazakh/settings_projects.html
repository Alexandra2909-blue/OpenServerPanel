Жобалардың глобалды баптаулары

Осы бөлімде орнатылған параметрлер жоба баптауларында басқа мәндер көрсетілмеген жағдайда қолданылады.

HTTP
Жобалар үшін қолданылатын веб-сервер түрін анықтайды.
NODE
Node.js қосымшаларын іске қосу үшін Node.js қозғалтқышын көрсетеді.

Node.js орнату: Алдымен NVM қосымшасын пайдаланып қажетті Node.js нұсқасын орнатыңыз.
PHP
PHP файлдарын өңдеу үшін қолданылатын PHP қозғалтқышын анықтайды.
Қосу
Жобаның әдепкі күйін анықтайды (қосылған немесе өшірілген).
Терминал кодтауы
Жоба ортасымен жұмыс істеу кезіндегі терминал кодтауы.

Арнайы мәндер:
- system: Жүйелік кодтау қолданылады.

Маңызды: Егер мән орнатылмаса, жобаның соңғы ортасын қалыптастыру кезінде терминал кодтауы соңғы қосылған ортамен орнатылады, мұнда ол анықталған, мысалы, PHP модулінің ортасы.
IP
Жеке баптаулары жоқ барлық жобалар қолданатын IP мекенжайды(ларды) орнатады.

Шектеу: Бірдей IP мекенжайды қолданатын жобалар PHP-тің бірдей нұсқасында жұмыс істеуі керек.

Көптеген IP қолдауы: IPv6 қоса алғанда, бос орынмен бөлінген бірнеше IP мекенжайларын көрсете аласыз. HOSTS файлында домендерге көрсетілген бірінші IP тағайындалады.

Автоматты тағайындау: Егер өрісті бос қалдырсаңыз, IP мекенжайы автоматты түрде тағайындалады.

Ұсыныстар:
  • IP мекенжайларын автоматты басқару көпшілік пайдаланушыларға ұсынылады.
  • IP мекенжайын қолмен орнату тек желілік конфигурацияның нақты талаптары үшін қолданылуы керек.
HTTP
HTTP қосылымдары үшін портты анықтайды.
HTTPS
HTTPS қосылымдары үшін портты анықтайды.
SSL
Жеке баптаулары жоқ жобалар үшін SSL қолдауын қосады немесе өшіреді.
H2
Жеке баптаулары жоқ жобалар үшін HTTP/2 қолдауын қосады немесе өшіреді.
Сертификат файлы
SSL сертификат файлына жолды көрсетеді. Үлгі айнымалыларын пайдалануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:

Ұсыныс: Сертификаттарды автоматты генерациялау үшін өрісті бос қалдырыңыз.
Кілт файлы
SSL кілт файлына жолды көрсетеді. Үлгі айнымалыларын пайдалануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:

Ұсыныс: Кілтті автоматты генерациялау үшін өрісті бос қалдырыңыз.
IP мекенжайы (backend)
Backend-ке қосылу үшін IP мекенжайын көрсетеді.
Порт (backend)
Backend-ке қосылу үшін порт нөмірін анықтайды.
Қосу (backend)
Жобаның барлық кіріс трафигін (HTTP және HTTPS) backend-ке автоматты бағыттауға мүмкіндік береді. Frontend және backend бөлінген кезде тестілеу немесе дамыту үшін пайдалы.
Жоба каталогы
Жобаның түбірлік каталогын көрсетеді. Осы каталогқа өту osp project <DOMAIN> командасымен жоба ортасын белсендірумен бірге жүзеге асырылады. Үлгі айнымалыларын пайдалануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:
Ашық каталог
Жобаның ашық каталогын анықтайды. Үлгі айнымалыларын пайдалануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:
Бүркеншік аттар
Жоба үшін қосымша домен аттарын (бүркеншік аттарды) көрсетеді (бос орынмен бөлінген). Үлгі айнымалыларын пайдалануға болады.

Субдомендер: Егер бүркеншік атта нүкте болмаса, ол субдомен ретінде қарастырылады (мысалы, "www" -> "www.test.local").

Шектеу: "*" белгісі Windows HOSTS файлымен қолдау көрсетілмейді және DNS конфигурациясын талап етеді.
Жоба ортасы
Жоба ортасын қалыптастыратын қосымшалар мен модульдердің тізімі (бос орынмен бөлінген).

PHP/Nginx/Node.js модульдері: Осы модульдердің орталары әрқашан қосылады (домен үшін көрсетілсе) және бұл параметрде көрсетуді талап етпейді.
Жобаны іске қосу командасы
Жобаны іске қосу командасын анықтайды (мысалы, nodemon app.js). Үлгі айнымалыларын пайдалануға болады.
Жоба URL-ы
Open Server Panel-да Жобаны браузерде ашу таңдау кезінде ашылатын URL. Үлгі айнымалыларын пайдалануға болады.

Қолдану: CMS басқару панелінің URL-ын орната аласыз.

Үлгі айнымалылары

Айнымалы Сипаттама
{backend_ip} Backend қосылымының IP мекенжайы
{backend_port} Backend қосылымының порты
{base_dir} Жобаның түбірлік каталогы (.osp каталогы орналасқан жер)
{host} Домен атауы (халықаралық домендер үшін Punycode қолданылады)
{host_decoded} Көрінетін домен атауы (Punycode-сыз)
{host_scheme} Жобаға сұраным схемасы ("http" немесе "https", жоба баптауларындағы SSL параметріне байланысты)
{http_port} HTTP протоколы арқылы жобаға сұраным порты
{https_port} HTTPS протоколы арқылы жобаға сұраным порты
{web_engine} HTTP қозғалтқышы
{node_engine} NODE қозғалтқышы
{php_engine} PHP қозғалтқышы
{project_dir} Жобаның түбірлік каталогы
{public_dir} Жобаның ашық каталогы
{scheme_port} Жобаға сұраным порты (":{http_port}" немесе ":{https_port}", жоба баптауларындағы SSL параметріне байланысты).

Егер {http_port} немесе {https_port} стандартты мән 80 немесе 443 болса, онда {scheme_port} бос болады.
{root_dir} Open Server Panel түбірлік каталогы (толық жол)
{root_drive} Түбірлік каталог дискісі
{root_path} Open Server Panel түбірлік каталогына жол
{terminal_codepage} Консоль кодтауы
