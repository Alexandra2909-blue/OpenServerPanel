Global Project Settings

Parameters set in this section are used when no other values are specified in the project settings.

HTTP
Defines the web server type used for projects.
NODE
Specifies the Node.js engine for running Node.js applications.

Node.js Installation: First install the required Node.js version using the NVM addon.
PHP
Defines the PHP engine used for processing PHP files.
Enable
Defines the default project state (enabled or disabled).
Terminal Encoding
Terminal encoding when working with the project environment.

Special values:
- system: Uses system encoding.

Important: If the value is not set, when forming the final project environment, the terminal encoding will be set by the last connected environment where it is defined, for example, the PHP module environment.
IP
Sets the IP address(es) used by all projects without individual settings.

Limitation: Projects using the same IP address must run on the same PHP version.

Multiple IP support: You can specify multiple IP addresses separated by spaces, including IPv6. In the HOSTS file, domains will be assigned the first specified IP.

Automatic assignment: If you leave the field empty, the IP address will be assigned automatically.

Recommendations:
  • Automatic IP address management is recommended for most users.
  • Manual IP address setting should only be used for specific network configuration requirements.
HTTP
Defines the port for HTTP connections.
HTTPS
Defines the port for HTTPS connections.
SSL
Enables or disables SSL support for projects without individual settings.
H2
Enables or disables HTTP/2 support for projects without individual settings.
Certificate File
Specifies the path to the SSL certificate file. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:

Recommendation: Leave the field empty for automatic certificate generation.
Key File
Specifies the path to the SSL key file. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:

Recommendation: Leave the field empty for automatic key generation.
IP Address (backend)
Specifies the IP address for connecting to the backend.
Port (backend)
Defines the port number for connecting to the backend.
Enable (backend)
Allows automatic redirection of all incoming project traffic (HTTP and HTTPS) to the backend. Useful for testing or development when frontend and backend are separated.
Project Directory
Specifies the project root directory. Navigation to this directory is performed by the command osp project <DOMAIN> along with project environment activation. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:
Public Directory
Defines the project public directory. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:
Aliases
Specifies additional domain names (aliases) for the project (space-separated). Template variables can be used.

Subdomains: If an alias doesn't contain a dot, it's treated as a subdomain (e.g., "www" -> "www.test.local").

Limitation: The "*" symbol is not supported by the Windows HOSTS file and requires DNS configuration.
Project Environment
List of addons and modules (space-separated) that form the project environment.

PHP/Nginx/Node.js Modules: Environments of these modules are always connected (if specified for the domain) and don't require specification in this parameter.
Project Start Command
Defines the command to start the project (e.g., nodemon app.js). Template variables can be used.
Project URL
URL opened when selecting Open project in browser in Open Server Panel. Template variables can be used.

Application: You can set the CMS administration panel URL.

Template Variables

Variable Description
{backend_ip} Backend connection IP address
{backend_port} Backend connection port
{base_dir} Project root directory (where .osp directory is located)
{host} Domain name (Punycode is used for internationalized domains)
{host_decoded} Visible domain name (without Punycode)
{host_scheme} Project request scheme ("http" or "https", depends on SSL parameter in project settings)
{http_port} Project request port via HTTP protocol
{https_port} Project request port via HTTPS protocol
{web_engine} HTTP engine
{node_engine} NODE engine
{php_engine} PHP engine
{project_dir} Project root directory
{public_dir} Project public directory
{scheme_port} Project request port (":{http_port}" or ":{https_port}", depends on SSL parameter in project settings).

If {http_port} or {https_port} has standard value 80 or 443, then {scheme_port} will be empty.
{root_dir} Open Server Panel root directory (full path)
{root_drive} Root directory drive
{root_path} Path to Open Server Panel root directory
{terminal_codepage} Console encoding
