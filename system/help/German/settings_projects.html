Globale Projekteinstellungen

Die in diesem Abschnitt festgelegten Parameter werden verwendet, wenn in den Projekteinstellungen keine anderen Werte angegeben sind.

HTTP
Definiert den für Projekte verwendeten Webserver-Typ.
NODE
Gibt die Node.js-Engine für das Ausführen von Node.js-Anwendungen an.

Node.js-Installation: Installieren Sie zunächst die gewünschte Node.js-Version mit dem NVM-Add-on.
PHP
Definiert die verwendete PHP-Engine für die Verarbeitung von PHP-Dateien.
Aktivieren
Definiert den Standard-Projektstatus (aktiviert oder deaktiviert).
Terminal-Kodierung
Terminal-Kodierung bei der Arbeit mit der Projektumgebung.

Spezielle Werte:
- system: Verwendet die Systemkodierung.

Wichtig: Wenn der Wert nicht gesetzt ist, wird bei der Bildung der endgültigen Projektumgebung die Terminal-Kodierung von der zuletzt verbundenen Umgebung gesetzt, in der sie definiert ist, z.B. der PHP-Modul-Umgebung.
IP
Legt die IP-Adresse(n) fest, die von allen Projekten ohne individuelle Einstellungen verwendet wird.

Einschränkung: Projekte, die dieselbe IP-Adresse verwenden, müssen auf derselben PHP-Version laufen.

Mehrere IP-Unterstützung: Sie können mehrere IP-Adressen durch Leerzeichen getrennt angeben, einschließlich IPv6. In der HOSTS-Datei wird Domains die erste angegebene IP zugewiesen.

Automatische Zuweisung: Wenn Sie das Feld leer lassen, wird die IP-Adresse automatisch zugewiesen.

Empfehlungen:
  • Automatische IP-Adressen-Verwaltung wird für die meisten Benutzer empfohlen.
  • Manuelle IP-Adressen-Einstellung sollte nur bei spezifischen Netzwerk-Konfigurationsanforderungen verwendet werden.
HTTP
Definiert den Port für HTTP-Verbindungen.
HTTPS
Definiert den Port für HTTPS-Verbindungen.
SSL
Aktiviert oder deaktiviert SSL-Unterstützung für Projekte ohne individuelle Einstellungen.
H2
Aktiviert oder deaktiviert HTTP/2-Unterstützung für Projekte ohne individuelle Einstellungen.
Zertifikatsdatei
Gibt den Pfad zur SSL-Zertifikatsdatei an. Vorlagenvariablen können verwendet werden.

Erlaubte Zeichen: A-Za-z0-9-+_.\:

Empfehlung: Lassen Sie das Feld leer für automatische Zertifikatsgenerierung.
Schlüsseldatei
Gibt den Pfad zur SSL-Schlüsseldatei an. Vorlagenvariablen können verwendet werden.

Erlaubte Zeichen: A-Za-z0-9-+_.\:

Empfehlung: Lassen Sie das Feld leer für automatische Schlüsselgenerierung.
IP-Adresse (Backend)
Gibt die IP-Adresse für die Verbindung zum Backend an.
Port (Backend)
Definiert die Portnummer für die Verbindung zum Backend.
Aktivieren (Backend)
Ermöglicht die automatische Umleitung des gesamten eingehenden Projekt-Traffics (HTTP und HTTPS) zum Backend. Nützlich für Tests oder Entwicklung, wenn Frontend und Backend getrennt sind.
Projektverzeichnis
Gibt das Stamm-Projektverzeichnis an. Die Navigation zu diesem Verzeichnis erfolgt mit dem Befehl osp project <DOMAIN> gleichzeitig mit der Aktivierung der Projektumgebung. Vorlagenvariablen können verwendet werden.

Erlaubte Zeichen: A-Za-z0-9-+_.\:
Öffentliches Verzeichnis
Definiert das öffentliche Projektverzeichnis. Vorlagenvariablen können verwendet werden.

Erlaubte Zeichen: A-Za-z0-9-+_.\:
Aliase
Gibt zusätzliche Domainnamen (Aliase) für das Projekt an (leerzeichengetrennt). Vorlagenvariablen können verwendet werden.

Subdomains: Wenn ein Alias keinen Punkt enthält, wird er als Subdomain behandelt (z.B. "www" -> "www.test.local").

Einschränkung: Das Symbol "*" wird von der Windows HOSTS-Datei nicht unterstützt und erfordert DNS-Konfiguration.
Projektumgebung
Liste von Add-ons und Modulen (leerzeichengetrennt), die die Projektumgebung bilden.

PHP/Nginx/Node.js-Module: Umgebungen dieser Module werden immer verbunden (wenn für die Domain angegeben) und erfordern keine Angabe in diesem Parameter.
Projekt-Startbefehl
Definiert den Befehl zum Starten des Projekts (z.B. nodemon app.js). Vorlagenvariablen können verwendet werden.
Projekt-URL
URL, die beim Auswählen von Projekt im Browser öffnen im Open Server Panel geöffnet wird. Vorlagenvariablen können verwendet werden.

Anwendung: Sie können die URL des CMS-Administrationsbereichs festlegen.

Vorlagenvariablen

Variable Beschreibung
{backend_ip} Backend-Verbindungs-IP-Adresse
{backend_port} Backend-Verbindungsport
{base_dir} Projekt-Stammverzeichnis (wo sich das .osp-Verzeichnis befindet)
{host} Domainname (für internationalisierte Domains wird Punycode verwendet)
{host_decoded} Sichtbarer Domainname (ohne Punycode)
{host_scheme} Projekt-Anfragenschema ("http" oder "https", abhängig vom SSL-Parameter in den Projekteinstellungen)
{http_port} Projekt-Anfrageport über HTTP-Protokoll
{https_port} Projekt-Anfrageport über HTTPS-Protokoll
{web_engine} HTTP-Engine
{node_engine} NODE-Engine
{php_engine} PHP-Engine
{project_dir} Projekt-Stammverzeichnis
{public_dir} Öffentliches Projektverzeichnis
{scheme_port} Projekt-Anfrageport (":{http_port}" oder ":{https_port}", abhängig vom SSL-Parameter in den Projekteinstellungen).

Wenn {http_port} oder {https_port} den Standardwert 80 oder 443 hat, ist {scheme_port} leer.
{root_dir} Open Server Panel Stammverzeichnis (vollständiger Pfad)
{root_drive} Stammverzeichnis-Laufwerk
{root_path} Pfad zum Open Server Panel Stammverzeichnis
{terminal_codepage} Konsolen-Kodierung
