Impostazioni Globali dei Progetti

I parametri impostati in questa sezione vengono utilizzati quando nelle impostazioni del progetto non sono specificati altri valori.

HTTP
Definisce il tipo di server web utilizzato per i progetti.
NODE
Specifica il motore Node.js per eseguire applicazioni Node.js.

Installazione Node.js: Prima installare la versione richiesta di Node.js utilizzando l'addon NVM.
PHP
Definisce il motore PHP utilizzato per elaborare i file PHP.
Abilita
Definisce lo stato predefinito del progetto (abilitato o disabilitato).
Codifica del Terminale
Codifica del terminale quando si lavora con l'ambiente del progetto.

Valori speciali:
- system: Utilizza la codifica di sistema.

Importante: Se il valore non è impostato, durante la formazione dell'ambiente finale del progetto, la codifica del terminale sarà impostata dall'ultimo ambiente connesso in cui è definita, ad esempio, l'ambiente del modulo PHP.
IP
Imposta l'indirizzo(i) IP utilizzato da tutti i progetti senza impostazioni individuali.

Limitazione: I progetti che utilizzano lo stesso indirizzo IP devono funzionare sulla stessa versione di PHP.

Supporto IP multipli: È possibile specificare più indirizzi IP separati da spazi, incluso IPv6. Nel file HOSTS, ai domini verrà assegnato il primo IP specificato.

Assegnazione automatica: Se si lascia il campo vuoto, l'indirizzo IP verrà assegnato automaticamente.

Raccomandazioni:
  • La gestione automatica degli indirizzi IP è raccomandata per la maggior parte degli utenti.
  • L'impostazione manuale dell'indirizzo IP dovrebbe essere utilizzata solo per requisiti specifici di configurazione di rete.
HTTP
Definisce la porta per le connessioni HTTP.
HTTPS
Definisce la porta per le connessioni HTTPS.
SSL
Abilita o disabilita il supporto SSL per progetti senza impostazioni individuali.
H2
Abilita o disabilita il supporto HTTP/2 per progetti senza impostazioni individuali.
File Certificato
Specifica il percorso del file del certificato SSL. Possono essere utilizzate variabili modello.

Caratteri consentiti: A-Za-z0-9-+_.\:

Raccomandazione: Lasciare il campo vuoto per la generazione automatica dei certificati.
File Chiave
Specifica il percorso del file della chiave SSL. Possono essere utilizzate variabili modello.

Caratteri consentiti: A-Za-z0-9-+_.\:

Raccomandazione: Lasciare il campo vuoto per la generazione automatica della chiave.
Indirizzo IP (backend)
Specifica l'indirizzo IP per la connessione al backend.
Porta (backend)
Definisce il numero di porta per la connessione al backend.
Abilita (backend)
Consente il reindirizzamento automatico di tutto il traffico in entrata del progetto (HTTP e HTTPS) al backend. Utile per test o sviluppo quando frontend e backend sono separati.
Directory del Progetto
Specifica la directory radice del progetto. La navigazione a questa directory viene eseguita con il comando osp project <DOMAIN> insieme all'attivazione dell'ambiente del progetto. Possono essere utilizzate variabili modello.

Caratteri consentiti: A-Za-z0-9-+_.\:
Directory Pubblica
Definisce la directory pubblica del progetto. Possono essere utilizzate variabili modello.

Caratteri consentiti: A-Za-z0-9-+_.\:
Alias
Specifica nomi di dominio aggiuntivi (alias) per il progetto (separati da spazi). Possono essere utilizzate variabili modello.

Sottodomini: Se un alias non contiene un punto, viene trattato come un sottodominio (es. "www" -> "www.test.local").

Limitazione: Il simbolo "*" non è supportato dal file HOSTS di Windows e richiede configurazione DNS.
Ambiente del Progetto
Elenco di addon e moduli (separati da spazi) che formano l'ambiente del progetto.

Moduli PHP/Nginx/Node.js: Gli ambienti di questi moduli sono sempre connessi (se specificati per il dominio) e non richiedono specificazione in questo parametro.
Comando di Avvio del Progetto
Definisce il comando per avviare il progetto (es. nodemon app.js). Possono essere utilizzate variabili modello.
URL del Progetto
URL che viene aperto quando si seleziona Apri progetto nel browser in Open Server Panel. Possono essere utilizzate variabili modello.

Applicazione: È possibile impostare l'URL del pannello di amministrazione CMS.

Variabili Modello

Variabile Descrizione
{backend_ip} Indirizzo IP di connessione al backend
{backend_port} Porta di connessione al backend
{base_dir} Directory radice del progetto (dove si trova la directory .osp)
{host} Nome del dominio (per domini internazionalizzati viene utilizzato Punycode)
{host_decoded} Nome di dominio visibile (senza Punycode)
{host_scheme} Schema di richiesta del progetto ("http" o "https", dipende dal parametro SSL nelle impostazioni del progetto)
{http_port} Porta di richiesta del progetto tramite protocollo HTTP
{https_port} Porta di richiesta del progetto tramite protocollo HTTPS
{web_engine} Motore HTTP
{node_engine} Motore NODE
{php_engine} Motore PHP
{project_dir} Directory radice del progetto
{public_dir} Directory pubblica del progetto
{scheme_port} Porta di richiesta del progetto (":{http_port}" o ":{https_port}", dipende dal parametro SSL nelle impostazioni del progetto).

Se {http_port} o {https_port} ha valore standard 80 o 443, allora {scheme_port} sarà vuoto.
{root_dir} Directory radice di Open Server Panel (percorso completo)
{root_drive} Unità della directory radice
{root_path} Percorso alla directory radice di Open Server Panel
{terminal_codepage} Codifica della console
